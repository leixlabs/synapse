- 类名带构建哈希（`video-card-sfaSzz`），全部用前缀匹配：
  卡片 = 同时含 `[class*="video-card-cover"]` 与 `[class*="info-title-text"]`
  且不含其它候选的**最内层** `video-card-*` 节点（防止将来列表容器套一层时吞掉全部卡片）；
  标题 `info-title-text*`，时间 `info-time*`（`2026年10月31日 07:03` → +08:00 ISO），

- 运营数据：卡片 9 个 metric 槽位（播放/点赞/评论/分享/收藏/弹幕/封面点击率/平均播放占比/吸粉量），

- 控制台不渲染账号昵称（在头像弹层里），所以 author 字段为空、服务端不写该字段。
- 同步改动：`lib/platforms.ts`（douyin 平台项 + 直达 URL，加入默认启用）、

## 抖音 collector：采集全部 9 个指标 + 解析作品 id（可播放链接）

- 指标从 5 个扩到 **9 个**：播放/点赞/评论/分享/收藏/弹幕/封面点击率/平均播放占比/吸粉量。
  `METRIC_LABELS` 按标签文本映射，`PERCENT_METRICS`（coverClickRate / avgPlayRatio）
  走 `parsePercentValue`（`6.51%` → 6.51，保留两位），其余走 `parseStatValue`。
- 类型 `EngagementMetrics` 新增 `fans / coverClickRate / avgPlayRatio`；
  服务端 `server/storage.go` 新增 `Fans *int`、`CoverClickRate/AvgPlayRatio *float64`
  （`strconv.FormatFloat(v,'f',-1,64)`），metrics front matter 键：
  `fans`、`cover_click_rate_pct`、`avg_play_ratio_pct`（百分比数值，6.51 = 6.51%），
  并同步 `metricsHasValues`。
- **作品 id 来源**：卡片 DOM 里没有任何 id（无 href / data-*，页面也不内嵌列表数据）。
  从控制台自身调用的列表 API 拿：`GET /janus/douyin/creator/pc/work_list`
  （在内容脚本内 fetch，同源 + 页面 cookie，无需签名），参数
  `status=0,1,2,3,6&count=20&max_cursor=<n>&scene=star_atlas&device_platform=android`，
  返回 `aweme_list[].aweme_id|item_id`、`create_time`、`desc`，另有 `items[].metrics`。
  状态枚举（来自 micro 包）：Create0 Reviewing1 Public2 AuditSelfSee3 AuthorDelete4 AutoCreate5 LiveReplay6。
  （另有 `/web/api/creator/item/list` 走数据中心权限，暂未用。）
- 匹配：先按 create_time（±60s）再按标题，命中即从池中 splice（避免一个 id 落到两张卡）。
  命中后 url = `https://www.douyin.com/user/self?modal_id=<id>`，video 类型再补
  `https://www.douyin.com/video/<id>` 到 links；去重键变成 `work-<id>`（稳定）。
  API 不可用/超时（10s race）时回退到「发布时间+封面 object key」锚点。
- 改动文件：`content/douyin-collector.ts`（fetchWorkIdentities / takeWorkIdentity /
  buildWorkLinks / collectAllWorksDouyin，auto-collect 与 popup 采集都改走异步）、
  `lib/types.d.ts`、`server/storage.go`、`content/collector.test.ts`
  （新增「Douyin work ids resolved from the list API」用例，mock window.fetch）。
- 测试：`bun test content/collector.test.ts` 10 pass / 0 fail（X.com 用例偶发 5s 超时，
  单独跑 --timeout 30000 通过）。eslint 0 error。
