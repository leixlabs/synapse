【一句话价值总结】 软件的下一个用户不是人，而是 agent。这期聊聊为什么 CLI 接口比 UI 更重要，以及独立开发者在 agent 时代的机会在哪里。 【核心要点】 • 软件选择新逻辑：未来买软件不是给自己用，而是给自己的 agent 用 • 双接口策略：做软件要同时提供 UI（给人）和 CLI（给 agent），单纯 UI 在 agent 流程中效率极低 • Agent 的核心优势：自主决策中间环节（报错、环境依赖等），不需要人工干预 • 软件形态演变：App → 脚本 / 文字描述 / 知识包
